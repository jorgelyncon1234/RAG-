# Intelligent RAG Assistant for Menus and Orders

This project consists of an intelligent assistant based on **RAG (Retrieval-Augmented Generation)** designed to answer questions about menus and orders. It simulates a real-world scenario, such as a customer asking for the most popular menu item or checking specific details.

While configured for a food service scenario, the underlying architecture can easily be adapted for deeper enterprise use cases by feeding it the appropriate corporate documentation and data.

##  Technologies Used
- **Python**
- **Groq API**
- **RAG Architecture** (Retrieval-Augmented Generation)
